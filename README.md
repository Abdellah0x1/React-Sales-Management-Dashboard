# 🧾 React Sales Management Dashboard

A **React Single Page Application (SPA)** that simulates a **sales management system**.  
The app allows managing products, creating orders, tracking stock, and visualizing sales data through an interactive dashboard.

This project is built for **learning and demonstration purposes**, focusing on modern React patterns, state management, routing, and UI design.

---

## 📌 Features

### 📊 Dashboard
- Sales history visualization using charts
- Overview of orders and sales performance

### 📦 Inventory Management
- View all products with image, price, category, and stock
- Add new products
- Edit existing products
- Delete products
- Update product stock
- Filter and sort products by category
- Search products by title or ID

### 🛒 Point of Sale (POS)
- Browse products in a card-based layout
- Add products to cart
- Increase / decrease quantities
- Remove items from cart
- Automatically calculate total price
- Create simulated orders

### 🔔 User Experience
- Toast notifications for actions (add, update, delete, order)
- Responsive layout
- Clean and modern UI

---

## 🛠 Tech Stack

### Frontend
- **React** (SPA architecture)
- **React Router** – client-side routing
- **Tailwind CSS** – styling
- **React Hot Toast** – notifications
- **Chart.js** – dashboard charts

### Backend (Mock API)
- **JSON Server**
- Product data sourced from **Amazon product JSON**
- REST-style API simulation
